# ABAP - Object naming

## When to use

Use this guide before creating, renaming, or validating any Y/Z object in the SAP repository.

## Workflow

1. Read [object-naming.md](object-naming.md).
2. To interpret `[MM]`, `[X]`, formats, or include suffixes, read [annex-tables.md](annex-tables.md).
3. For OData/service objects, also review the specific modeling section in `object-naming.md`.
4. Do not invent available sequence numbers: if the standard requires a free number, ask for it or check the system.
5. Preserve the exact prefixes and digit counts defined in these references.
